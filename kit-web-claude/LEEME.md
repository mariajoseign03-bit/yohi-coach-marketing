# Kit de diseño web para Claude

## Opción A · Proyecto de Claude (claude.ai → Proyectos)
1. Crea un proyecto, por ejemplo "Diseño web".
2. En **Instrucciones**, pega el contenido de `INSTRUCCIONES_PROYECTO.md`.
3. En **Conocimiento**, sube: `01` a `08`, `09-plantilla-base.html` y `10-preset-marca-yohi.md`.
4. Escribe en el proyecto, por ejemplo: "Crea la landing de [marca] con este brief: ...".

## Opción B · Skill (claude.ai → Configuración → Capacidades → Skills)
Sube `diseno-web-premium-skill.zip`. Claude la usa sola cuando pidas una web, en cualquier chat.
