# 01 · Proceso y brief

## Preguntas del brief (responder antes de diseñar)
| Pregunta | Por qué importa |
|---|---|
| ¿Qué es la marca y qué ofrece? | Define el contenido y las secciones |
| ¿Quién es el público? (edad, contexto, dispositivo) | Define tono, tamaño de letra, densidad |
| ¿Cuál es la ÚNICA acción que queremos? | Define el CTA principal y su repetición |
| ¿Qué tono? (3-5 adjetivos) | Define tipografía, color y animación |
| ¿Qué tiene que la diferencia? | Es el "momento de marca" del hero |
| ¿Qué datos reales tenemos? (contacto, precios, horarios, reseñas) | Lo que falte va como placeholder |
| ¿Referencias que le gustan / que odia? | Evita rehacer |

## Lectura de diseño (formato)
> **Estilo:** editorial lifestyle, oscuro con acentos rosa. **Tipos:** Anton (display) + Montserrat (texto). **Motion:** medio: hero orquestado + reveals suaves. **Riesgo creativo:** personaje ilustrado como protagonista.

## Los 3 diales (definir 1-10)
- **Variación visual:** 3 = sobrio y corporativo · 8 = editorial, asimétrico, con personalidad.
- **Intensidad de movimiento:** 2 = casi estático · 5 = reveals + hovers · 8 = parallax, cinética, momentos.
- **Densidad:** 3 = mucho aire (lujo, marca personal) · 7 = mucha información (dashboard, e-commerce).

Presets útiles:
| Tipo de sitio | Variación | Movimiento | Densidad |
|---|---|---|---|
| Marca personal / coach | 7 | 6 | 3 |
| Servicio de salud / clínica | 4 | 3 | 4 |
| Landing de producto | 6 | 6 | 4 |
| Portafolio creativo | 9 | 7 | 2 |
| Corporativo / seguros | 3 | 3 | 5 |

## Arquitectura de una landing que convierte
1. **Hero:** promesa en ≤ 8 palabras + subtítulo que explica + CTA principal + CTA secundario + imagen/personaje protagonista.
2. **Elección rápida:** 2-3 tarjetas "¿Qué buscas?" que derivan a cada servicio.
3. **Servicios:** qué incluye cada uno (bullets cortos) + CTA por servicio.
4. **Quién está detrás:** cercanía + credenciales (visual, no currículum).
5. **Valor / educación:** datos, "¿sabías que?", proceso en pasos.
6. **Prueba social:** reseñas reales (si no hay, tarjeta "muy pronto", nunca inventadas).
7. **Contacto:** formulario corto + canal directo (WhatsApp/Instagram).
8. **Footer:** marca grande, links, redes.

Regla: cada sección = una idea. Si una sección necesita dos títulos, son dos secciones.
