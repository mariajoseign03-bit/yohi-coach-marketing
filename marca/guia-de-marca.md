# Guía de marca — Yohi Coach

## Recursos
| Archivo | Uso |
|---|---|
| `logo-yohi-coach.png` | Logo principal (YOHI en sentadilla con barra). Cierres de video, perfil, portadas. |
| `personaje-yohi-pensando.png` | YOHI pensando con "??". Hooks de mitos, preguntas y "¿sabías que…?". |
| `sello-certified.jpg` | Sello. Usar solo con certificación real y verificable detrás. |

## Paleta
| Color | Hex | Uso |
|---|---|---|
| Negro | `#111111` | Fondo principal |
| Rosa YOHI | `#FF4FA3` | Acentos, títulos, CTA |
| Rosa suave | `#FFD6E8` | Fondos secundarios, tarjetas |
| Blanco | `#FFFFFF` | Texto principal sobre negro |
| Gris | `#8C8C8C` | Texto secundario, fuentes/citas |

## Contraste (legibilidad, WCAG)
| Combinación | Ratio | Veredicto |
|---|---|---|
| Blanco sobre negro | 18.9:1 | ✅ Ideal para texto largo |
| Rosa YOHI sobre negro | 6.2:1 | ✅ Títulos y texto |
| Gris sobre negro | 5.6:1 | ✅ Citas y fuentes |
| Negro sobre rosa suave | 14.4:1 | ✅ Tarjetas |
| Blanco sobre rosa YOHI | 3.0:1 | ⚠️ Solo títulos grandes; para texto usar **negro sobre rosa** |

## Estilo
Fitness + femenino + moderno. Fondos negros, detalles rosa, tipografías fuertes (estilo college/bloque),
fotos reales de entrenamiento y el personaje YOHI como elemento distintivo.
